## Аннотация

На данных СберИндекса (средние потребительские расходы на держателя карты за месяц, январь 2023 – декабрь 2024) и Росстата (население МО) построена типология 1125 муниципальных образований России. Из исходных временных рядов извлечены 8 признаков (уровень, динамика, сезонность, устойчивость). На их основе построен граф «МО ↔ МО» с косинусным сходством в качестве веса рёбер; для кластеризации применены KMeans (k=4), Ward и GMM, а также алгоритм Louvain для выделения графовых сообществ.

**Итог:** 4 макротипа локальных экономик (стабильное ядро, растущие обеспеченные территории, стагнирующая периферия, северные сезонные территории) и 11 графовых сообществ (модулярность Q=0.635). Устойчивость разметки подтверждена 6 сценариями робастности (ARI = 0.94 при подвыборках).

## Быстрый старт

### Шаг 1. Клонировать репозиторий

```bash
git clone [https://github.com/ВАШ_ЛОГИН/mo-clustering-sberindex.git](https://github.com/ВАШ_ЛОГИН/mo-clustering-sberindex.git)
cd mo-clustering-sberindex
```

### Шаг 2. Создать виртуальное окружение и установить зависимости

**Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Windows (PowerShell):**
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

> 💡 Если PowerShell блокирует активацию venv, выполните один раз:


```bash
python run_all.py --config config.yaml --step all
```

## Запуск отдельных шагов

Если нужно перезапустить только часть пайплайна, используйте флаг `--step`:

```bash
# Только подготовка данных
python run_all.py --config config.yaml --step prep

# Только кластеризация (плюс все её зависимости: prep → features → preprocess → select_k)
python run_all.py --config config.yaml --step cluster

# Только граф поверх уже готовой кластеризации
python run_all.py --config config.yaml --step graph
```

**Доступные значения `--step`:** `prep`, `features`, `diagnostics`, `preprocess`, `select_k`, `cluster`, `profile`, `viz_clusters`, `viz_profiles`, `robust`, `graph`, `all`.

> ℹ️ Скрипт сам подтянет все зависимости: например, `--step cluster` автоматически выполнит `prep → features → preprocess → select_k → cluster`.

### Переопределение числа кластеров

```bash
# Запустить с фиксированным k=4 (по умолчанию — auto-подбор)
python run_all.py --config config.yaml --step cluster --k 4
```

Флаг `--k` перезаписывает значение k в `config.yaml`.

### Запуск отдельного скрипта напрямую

```bash
python src/s01_prep.py --config config.yaml
python src/s02_features.py --config config.yaml
# ... и так далее
```

Каждый скрипт принимает только `--config config.yaml` (кроме `s07_profile.py` с `--labels` и `s08_viz_clusters.py` с `--interactive`).

## Метод

### Признаки (8 из 11)

Относительный ряд: `r(i,t) = ln y(i,t) − медиана_j ln y(j,t)`

Регрессия: `r = α + β·t̃ + Σ γₘ·[месяц=m] + ε`, где `t̃ = t − 11.5`, `Σγₘ = 0`

| Код | Определение | Блок |
|-----|-------------|------|
| **A1** | среднее r за 24 мес | Уровень |
| **B1** | β (наклон) | Динамика |
| **C1** | max s(m) − min s(m) | Сезонность |
| **C2** | (2/12)·Σ s(m)·cos(2π(m−1)/12) | Сезонность |
| **C3** | (2/12)·Σ s(m)·sin(2π(m−1)/12) | Сезонность |
| **C5** | s(декабрь) | Сезонность |
| **D1** | √(SSE/11) | Устойчивость |
| **D2** | доля \|Δε\| > 3·1.4826·MAD | Устойчивость |

**Исключены:** A2, B2, C4 — как дубли (\|corr\| > 0.9, VIF > 10).

### Предобработка

- Winsorize 1–99 перцентиль
- Робастная стандартизация: `(x − медиана) / IQR`
- Блочный вес `1/√k` на признаки каждого блока

### Рёбра графа

Ребро `(i,j)` существует, если косинусное сходство векторов признаков `wᵢⱼ = ⟨xᵢ,xⱼ⟩ / (‖xᵢ‖·‖xⱼ‖)` превышает порог или `j ∈ kNN(i)`.

- **kNN (k=15):** для каждого МО — 15 ближайших соседей
- **Порог:** `wᵢⱼ ≥ 0.9`

> 💡 **Обоснование:** косинус инвариантен к масштабу, устойчив к разной «энергетике» векторов, соответствует содержательному понятию «похожий профиль потребления».

### Кластеризация

| Метод | Параметры |
|-------|-----------|
| **KMeans** | `n_init=50`, `random_state=42`, `k=4` |
| **Ward** | `linkage=ward`, согласован с KMeans через венгерский алгоритм |
| **GMM** | `full/tied/diag` по BIC, `n_init=5` |
| **Louvain** | модулярность Q, `resolution=1.0` — на графе |

**Выбор k=4 обоснован:** ARI KMeans–Ward = 0.596, bootstrap ARI = 0.895 ± 0.058, BIC GMM минимален (164.4), 4 макротипа содержательны.

## Результаты

### 4 макротипа

| Кластер | n | % | Профиль | Топ-субъекты |
|---------|---|---|---------|--------------|
| **0. Стагнирующая периферия** | 289 | 25.7 | Уровень ниже среднего, падение | Башкортостан, Татарстан, Оренбургская |
| **1. Стабильное ядро** | 528 | 46.9 | Около медианы, низкая волатильность | Нижегородская, Алтайский край |
| **2. Растущие обеспеченные** | 258 | 22.9 | Высокий уровень, быстрый рост | Башкортостан, Ленинградская, Татарстан |
| **3. Северные сезонные** | 50 | 4.4 | Гипер-сезонность, летний/декабрьский пик | Якутия, Камчатка, Тыва, Алтай |

Различия подтверждены Краскел-Уоллисом (все p < 10⁻⁴) и размером эффекта (η² = 0.59 для B1, 0.48 для A2, 0.17 для C1).

### Графовые сообщества

- **Граф по косинусу + kNN(15):** 1125 узлов, 10 975 рёбер, средняя степень 19.5
- **Louvain:** 11 сообществ, модулярность Q = 0.635
- **ARI(KMeans, Louvain) = 0.179**

> 📌 **Два уровня описывают разные аспекты:**  
> - **KMeans (k=4)** — макротипы по уровню и динамике  
> - **Louvain (11)** — микроструктура «клан»-групп с почти идентичным профилем признаков
