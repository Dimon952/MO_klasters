# Типология российских муниципалитетов по структуре потребительского поведения (2023–2024)

**Конкурс:** СберИндекс — Кластеризация муниципалитетов РФ.
**Задача:** Построить типологию муниципальных образований (МО) России по поведенческо-временным характеристикам безналичных потребительских расходов на основе атрибутированной динамической сети.

**Ключевой результат:**
- 1125 МО × 24 месяца (январь 2023 – декабрь 2024);
- 8 признаков из 4 блоков (уровень, динамика, сезонность, устойчивость);
- 4 макротипа локальных экономик (KMeans);
- 11 графовых сообществ (Louvain, модулярность Q = 0.635);
- устойчивость разметки: ARI = 0.94 при подвыборках.

**Стек:** Python 3.10+, pandas, numpy, scikit-learn, networkx, python-louvain, matplotlib, seaborn, plotly.

## Аннотация

На данных СберИндекса (средние потребительские расходы на держателя карты за месяц, январь 2023 – декабрь 2024) и Росстата (население МО) построена типология 1125 муниципальных образований России. Из исходных временных рядов извлечены 8 признаков (уровень, динамика, сезонность, устойчивость). На их основе построен граф «МО ↔ МО» с косинусным сходством в качестве веса рёбер; для кластеризации применены KMeans (k=4), Ward и GMM, а также алгоритм Louvain для выделения графовых сообществ. Итог — 4 макротипа локальных экономик (стабильное ядро, растущие обеспеченные территории, стагнирующая периферия, северные сезонные территории) и 11 графовых сообществ (модулярность Q=0.635). Устойчивость разметки подтверждена 6 сценариями робастности (ARI = 0.94 при подвыборках).

**## Запуск отдельных шагов (для отладки)**
Если нужно перезапустить только часть пайплайна, используйте флаг --step:

# Только подготовка данных
python run_all.py --config config.yaml --step prep

# Только кластеризация (плюс все её зависимости: prep → features → preprocess → select_k)
python run_all.py --config config.yaml --step cluster

# Только граф поверх уже готовой кластеризации

Доступные значения --step: prep, features, diagnostics, preprocess, select_k, cluster, profile, viz_clusters, viz_profiles, robust, graph, all.

Скрипт сам подтянет все зависимости: например, --step cluster автоматически выполнит prep → features → preprocess → select_k → cluster.

Формат входных данных
table1.xlsx — long-формат, СберИндекс:
period, value, category_15, mo, freq, decimals, unit_measure, unit_mult.

period — M/D/YY H:MM (например, 1/1/23 0:00).

value — средний расход на держателя карты за месяц, руб.

используется только category_15 == "Все категории".

table2.xlsx — справочник МО, Росстат:
Федеральный округ, Субъект, МО, Население 2023, Население 2024.

Важно: если названия МО в таблице 2 не уникальны (например, «Александровский муниципальный район» есть в нескольких субъектах), МО с неуникальным названием исключаются из кластеризации — без ОКТМО однозначное соединение невозможно. Полный список исключённых — в out/tables/duplicated_mo_names.csv.

Метод
Признаки (8 из 11)
Относительный ряд: r(i,t) = ln y(i,t) − медиана_j ln y(j,t).

Регрессия: r = α + β·t̃ + Σ γₘ·[месяц=m] + ε, t̃ = t − 11.5, Σγₘ = 0.

Код	Определение	Блок
A1	среднее r за 24 мес	Уровень
B1	β (наклон)	Динамика
C1	max s(m) − min s(m)	Сезонность
C2	(2/12)·Σ s(m)·cos(2π(m−1)/12)	Сезонность
C3	(2/12)·Σ s(m)·sin(2π(m−1)/12)	Сезонность
C5	s(декабрь)	Сезонность
D1	√(SSE/11)	Устойчивость
D2	доля |Δε| > 3·1.4826·MAD	Устойчивость
Исключены A2, B2, C4 — как дубли (|corr| > 0.9, VIF > 10).

Предобработка: winsorize 1–99 перцентиль; робастная стандартизация (x − медиана)/IQR; блочный вес 1/√k на признаки каждого блока.

Рёбра графа
Ребро (i,j) существует, если косинусное сходство векторов признаков wᵢⱼ = ⟨xᵢ,xⱼ⟩ / (‖xᵢ‖·‖xⱼ‖) превышает порог или j ∈ kNN(i).

kNN (k=15): для каждого МО — 15 ближайших соседей.

Порог: wᵢⱼ ≥ 0.9.

Обоснование: косинус инвариантен к масштабу, устойчив к разной «энергетике» векторов, соответствует содержательному понятию «похожий профиль потребления».

Кластеризация
KMeans (n_init=50, random_state=42), k=4.

Ward (linkage=ward), согласован с KMeans через венгерский алгоритм.

GMM (full/tied/diag по BIC, n_init=5).

Louvain (модулярность Q, resolution=1.0) — на графе.

Выбор k=4 обоснован: ARI KMeans–Ward = 0.596, bootstrap ARI = 0.895 ± 0.058, BIC GMM минимален (164.4), 4 макротипа содержательны.

Графовые сообщества
Граф по косинусу + kNN(15): 1125 узлов, 10 975 рёбер, средняя степень 19.5. Louvain: 11 сообществ, модулярность Q = 0.635. ARI(KMeans, Louvain) = 0.179.

Два уровня описывают разные аспекты:

KMeans (k=4) — макротипы по уровню и динамике.

Louvain (11) — микроструктура «клан»-групп с почти идентичным профилем признаков.

Ограничения и что можно улучшить
Без ОКТМО ~530 МО потеряны из-за неуникальных названий. Решение — использовать ОКТМО из первоисточника.

Категорийные доли (продовольствие, транспорт и т. д.) не включались в кластеризацию, но могли бы усилить интерпретацию. Решение — CLR/ILR-преобразование композиционных данных.

GMM расходится с KMeans (ARI = 0.05). Решение — отдельная мягкая кластеризация для вероятностной интерпретации.

Louvain даёт 11 сообществ — для интерпретации в отчёте детально разобраны только топ-5.
